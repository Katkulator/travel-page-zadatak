# Travel Homepage

Frontend travel landing page built with Vite and Swiper.

## Stack

- Vite
- Vanilla JavaScript
- Swiper
- Modular CSS

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the local dev URL printed by Vite in your browser.

## Test On Phone

Start the dev server on all network interfaces:

```bash
npm run dev -- --host 0.0.0.0
```

Then use the `Network` URL printed by Vite, for example:

```text
http://192.168.50.1:5173/
```

Open that address on your phone.

Requirements:

- your phone and computer must be on the same Wi-Fi network
- the dev server must still be running
- your firewall must allow connections to port `5173`

If the dev server does not work on your phone, you can also preview the production build over the local network:

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

Then open the `Network` URL printed by Vite on your phone.

## Project Structure

```text
.
├── assets/                # Static images used by the app
├── src/
│   ├── partials/          # HTML partials rendered into the app root
│   └── scripts/
│       ├── main.js        # App bootstrap
│       ├── render.js      # Partial rendering and slide markup
│       ├── swipers.js     # Swiper initialization
│       ├── nav.js         # Navigation behavior
│       ├── animations.js  # Load and reveal animations
│       └── content-data.js # Static page content data
├── styles/
│   ├── base/
│   ├── components/
│   ├── layout/
│   ├── overrides/
│   ├── sections/
│   └── utilities/
├── index.html
└── package.json
```

## Notes

- `index.html` loads the app from `src/scripts/main.js`.
- Travel cards and sliders are rendered from data in `src/scripts/content-data.js`.
- Design tokens live in `styles/base/tokens.css`.
- `dist/` is generated by `npm run build` and is ignored in Git.
